# AI Factory

AI Factory is a design-stage product for reusable, subscription-based software production in Codex Cloud. Product requirements, architecture and the complete v1.0 technical handoff are documented; the factory runtime has not been implemented.

The approved v1.0 runtime is Codex Cloud under a ChatGPT plan with native subagents in one root task. Open Cloud-specific feasibility checks are recorded as unverified until WP0 is run in the intended account. No API-based runtime or manual child-task relay is part of the design.
